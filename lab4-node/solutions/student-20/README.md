# Бот для магазина одежды "FashionAssistant 2"

## Описание проекта
Бот aliccedress - это онлайн-консультант для магазина одежды. С помощью него можно:
1. Посмотреть каталог по категориям (мужская, женская и детская одежда)
2. Посмотреть доступные товары
3. Посмотреть цены и доступные размеры
4. Проконсультироваться у бота, он поможет выбрать товар под конкретный запрос
5. Бот реагирует только на инлайн-кнопки, сообщения не обрабатывает


## Инструкция по запуску
1. Клонируйте и перейдите в папку с решением:
2. Установите зависимости (npm install)
3. Создайте локальный `.env` 
4. Запустите тесты (npm test)
5. Запустите проверку ошибок (npm run lint)
